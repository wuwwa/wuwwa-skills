# Lot Vulture

Saved repo · Checked 2026-11-07 · Not installed

Camera-based parking occupancy and analytics. Uses existing IP/RTSP camera feeds, a Python backend and a Vue dashboard; an on-device inference engine determines parking-space occupancy.

Useful to revisit for camera-fed mapping, parking dashboards, occupancy history and alerting. It is a complete application, not an agent skill or drop-in UI library.

The README describes a Windows installer, Linux Docker image and Compose setup. Those routes have not been run here. Before evaluating it, inspect current release assets, hardware requirements and the setup docs for the chosen platform. Use sample input for evaluation; a saved reference does not authorize connecting a camera.

Source documents identify a community CPU edition, commercial GPU/model features and the Lot Vulture Source License 1.0.0, adapted from PolyForm Shield. Read the current upstream terms before reuse; the repo is source-available rather than MIT-licensed.
