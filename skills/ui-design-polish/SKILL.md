# UI Design

Make the main action obvious. Follow the project's brand and the user's references.

Use these as review cues, not blanket bans:

- Remove redundant copy and ornamental UI details.
- Use spacing before adding bordered containers or dividers.
- Keep pills, breadcrumbs, section numbers, and eyebrow labels only when useful.
- Choose fonts for the product; avoid defaulting to Instrument Serif for atmosphere.
- Use italics, monospace, all-caps subtitles, and tight letter spacing sparingly.
- Keep color shades and opacity levels consistent and readable.
- Use gradients, squircles, dithering, and ASCII art when they fit the requested style.
- Simplify diagrams to the information people need.
- Omit periods from standalone titles unless the established style calls for them.
- Preserve useful information density, contrast, focus states, and responsive layout.

Check the changed screen with realistic content at relevant sizes.
